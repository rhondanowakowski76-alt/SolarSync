# Security Policy

## Reporting a vulnerability

Please **do not** report security problems in public issues, pull requests or discussions.

Report them privately instead:

1. Go to the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Describe the problem, the steps to reproduce it, and what could be affected.

We aim to acknowledge reports within 5 business days and to keep you updated until the issue is resolved. Please give us reasonable time to fix a problem before sharing it with anyone else.

## Scope

In scope: the SolarSync web app and server code in this repository.

Out of scope: third-party services SolarSync connects to (for example Stripe, MYOB, DigitalOcean or the AI provider). Report those to the provider directly.

## Please don't

- Access, change or delete other people's data.
- Run denial-of-service or automated high-volume tests against the live site.
- Use social engineering or phishing against SolarSync users or staff.

## Supported versions

Only the current version on the `main` branch (the live site) receives security fixes.
